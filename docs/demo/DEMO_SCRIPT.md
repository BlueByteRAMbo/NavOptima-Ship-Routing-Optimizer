# NavOptima Demonstration & Evaluation Script

## Objective
Demonstrate the end-to-end capabilities of NavOptima:
1. Port selection and origin-destination pair configuration.
2. Unified environmental grid visualization across the Indian Ocean (Weather, Waves, Currents, Risk, Traffic).
3. Route calculation and multi-objective Pareto trade-off comparison.
4. Dynamic event simulation and mid-voyage rerouting.

## Test Scenarios
- **Scenario A**: High-Risk Piracy Avoidance (Gulf of Aden / Arabian Sea Corridor).
- **Scenario B**: Heavy Monsoon Wave & Wind Routing (Bay of Bengal / South Indian Ocean).
- **Scenario C**: Traffic Congestion Avoidance (Malacca Strait / Singapore approach).
