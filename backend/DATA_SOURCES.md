## NOAA GFS/NOMADS

- **Official URL:** https://nomads.ncep.noaa.gov/
- **Purpose:** Wind speed/direction (10m) for the environment grid
- **Authentication:** None (public GRIB filter service)
- **API/tool:** NOMADS GRIB filter (`filter_gfs_0p25.pl`) + `xarray` + `cfgrib`
- **Variables:** UGRD, VGRD @ 10m above ground
- **Format:** GRIB2
- **Spatial resolution:** 0.25° native → resampled to 0.5° common grid
- **Temporal resolution:** hourly/3-hourly forecast cycles (00/06/12/18z)
- **Indian Ocean subset:** lat [-32, 26], lon [25, 105]
- **Processing:** GRIB filter subset → xarray/cfgrib → derive speed & direction from U/V
- **Cache:** raw GRIB2 in `data/raw/noaa/`, normalized JSON in `data/processed/weather/`
- **Status:** MOCK (script ready, not run — no network in this environment)
- **Usage/licensing:** Public domain (US government data)
- **Fallback:** `build_environment_grid.py` simulated monsoon-like wind field

## Copernicus Marine

- **Official URL:** https://marine.copernicus.eu/
- **Purpose:** Ocean currents (U/V) and wave height/period
- **Authentication:** Free account required; credentials via env vars (`COPERNICUSMARINE_SERVICE_USERNAME/PASSWORD`)
- **API/tool:** official `copernicusmarine` Python toolbox (`subset()`)
- **Variables:** uo, vo (currents), VHM0, VTPK (waves)
- **Format:** NetCDF
- **Spatial resolution:** ~0.083° native → resampled to 0.5° common grid, surface layer only
- **Temporal resolution:** hourly/3-hourly analysis-forecast
- **Indian Ocean subset:** lat [-32, 26], lon [25, 105]
- **Processing:** `copernicusmarine.subset()` → xarray → normalize → regrid
- **Cache:** raw NetCDF in `data/raw/copernicus/`, normalized JSON in `data/processed/ocean/`
- **Status:** MOCK (script ready, not run — no network/account in this environment)
- **Usage/licensing:** Copernicus Marine Service open license, attribution required
- **Fallback:** `build_environment_grid.py` simulated current/wave field

## ACLED

- **Official URL:** https://acleddata.com/
- **Purpose:** Conflict/security events → one input into a simplified security-risk model
- **Authentication:** Registered account + API key + email, via env vars (`ACLED_API_KEY`, `ACLED_EMAIL`)
- **API/tool:** official ACLED REST API (`/acled/read`)
- **Variables:** event_type, latitude, longitude, fatalities, event_date
- **Format:** JSON
- **Spatial resolution:** point events, converted to 75km decay-radius zones
- **Temporal resolution:** configurable window (default last 90 days)
- **Indian Ocean subset:** lat [-32, 26], lon [25, 105]
- **Processing:** REST query (region/date filtered) → severity heuristic (`0.2 + 0.1*fatalities`, capped at 1.0) → security zones
- **Cache:** raw JSON in `data/raw/acled/`, normalized JSON in `data/processed/security/`
- **Status:** MOCK (script ready, not run — no account/network in this environment; `cache/security_events.json` has one illustrative demo zone)
- **Usage/licensing:** ACLED terms of use — non-commercial/registered use
- **Fallback:** `acled_ingest.py --mock` writes a single illustrative demo zone
- **Important:** ACLED is a conflict-event dataset, **not** a dedicated maritime piracy API — treated as one signal among several.

## Global Fishing Watch

- **Official URL:** https://globalfishingwatch.org/our-apis/
- **Purpose:** AIS-derived vessel activity → traffic_density proxy
- **Authentication:** Account + API token via env var (`GFW_API_TOKEN`)
- **API/tool:** GFW API v3, 4Wings report endpoint
- **Variables:** apparent fishing effort (proxy for activity density)
- **Format:** JSON
- **Spatial resolution:** 1.0° (coarser — traffic signal is sparse)
- **Temporal resolution:** configurable window (default last 30 days)
- **Indian Ocean subset:** lat [-32, 26], lon [25, 105]
- **Processing:** 4Wings query → normalize value to 0-1 traffic_density
- **Cache:** normalized JSON in `data/processed/traffic/`, mock in `data/cache/traffic_density_demo.json`
- **Status:** MOCK (P2, per spec section 17 — explicitly allowed to fall back; currently active)
- **Usage/licensing:** GFW API terms, attribution required
- **Fallback:** `gfw_ingest.py --mock` — port-proximity decay model (currently in use)
- **Important:** represents AIS-visible fishing-vessel activity, **not** all vessel traffic in the ocean.

## Port data (15 canonical ports)

- **Official URL:** n/a (curated static dataset)
- **Purpose:** Port operational context (congestion, waiting time) for routing cost
- **Authentication:** n/a
- **API/tool:** `ports_ingest.py`, static curated list
- **Variables:** id, name, country, lat, lon, congestion, waiting_hours, utilization
- **Format:** JSON
- **Spatial resolution:** point locations (15 ports)
- **Temporal resolution:** static, congestion/waiting_hours simulated per run
- **Indian Ocean subset:** all 15 ports fall within lat [-32, 26], lon [25, 105]
- **Processing:** curated coordinates + deterministic simulated congestion (seeded RNG)
- **Cache:** `data/cache/ports.json`
- **Status:** MOCK
- **Usage/licensing:** n/a
- **Fallback:** n/a — this IS the fallback/canonical dataset
- **Important:** coordinates are compiled from public geographic references and have **not** been cross-validated against an official port-authority API. Recommend verification before any non-hackathon use.
